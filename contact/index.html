Contact

Contact

Email hello@editloft.com. I read every message myself and reply within a few business days.

What to write about

  • A question about Editloft
  • Something on this site that is wrong, broken or out of date
  • A problem using the site with a screen reader, a keyboard or other assistive technology (see accessibility)

Bugs in the plugin

For a bug in the plugin, a GitHub issue is better than an email, because the next person with the same problem can find it. Editloft is a personal project, not a supported commercial product, so I cannot promise a response time on issues, but I read every one. The support page covers the common questions.

What happens to your message

There is no contact form, so your message never touches this website. It goes straight to my inbox, and I use it only to reply to you. The privacy page has the details.
