Requirements

  • WordPress 6.4 or newer
  • PHP 7.4 or newer

If you are not sure which versions you run, both appear under Tools, then Site Health, then Info in your dashboard.

Install

  1. Download the release .zip from the latest release on GitHub.
  2. In your dashboard, go to Plugins, then Add New Plugin, then Upload Plugin.
  3. Choose the zip, select Install Now, then Activate.
  4. Open Editloft in the admin menu and switch on the modules you want: the calendar, the audit trail and status transitions.

Prefer the command line? Clone the repository into wp-content/plugins/editloft and activate it from the Plugins screen.

Upgrading and moving from Edit Flow

Back up your site and try Editloft on a staging copy first, as you would with any plugin. If you are moving from Edit Flow, deactivate Edit Flow before you activate Editloft, because the two overlap. There is no migration tool, and Editloft has no custom statuses or editorial comments to import. Read the comparison first so you know what changes.

If you are on version 0.6194.1016 or 0.6199.0938, update: those builds contain a bug that broke saving from the block editor, fixed in 0.6218.1049.
