Before you start

Requirements

Editloft needs a reasonably current site to run cleanly:

WordPress 6.4 or newer PHP 7.4 or newer

If you are not sure what versions you are on, both appear under Tools, then Site Health, then Info in your WordPress dashboard. Most managed hosts keep you well above these baselines already.

Get the file

Download

The current release lives on GitHub, where every version is public and dated. Download the plugin zip from the latest release. That zip is the same file you upload to your site in the next step.

Download the latest release View the repository

Install

Installing it

Once you have the zip:

  1. In your WordPress dashboard, go to Plugins, then Add New Plugin, then Upload Plugin.
  2. Choose the Editloft zip you downloaded and select Install Now.
  3. When the upload finishes, select Activate.

That is the whole process. After activation you will find Editloft’s settings in the dashboard, and you can start moving stories through custom statuses right away.
